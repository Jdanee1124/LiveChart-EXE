# SHXJ-LiveChart - 工业实时波形监测与分析程序

专用于工业机器视觉（如台达 DMV、VisionMaster）、传感器测厚、线缆测径与位移监控的轻量级实时数据流展示与分析软件。

---

## 🎯 核心特性与架构

1. **三种主流工业通信模式全支持**：
   - **网络通讯 (服务端 / TCP Server)**：默认监听 `127.0.0.1:3000`（支持局域网 `0.0.0.0`），支持多客户端连入。
   - **网络通讯 (客户端 / TCP Client)**：主动连接外部 PLC 或视觉主机，具备后台断线自动重试重连机制。
   - **串口通讯 (Serial Port / COM)**：支持物理串口与虚拟串口（VSPD），具备可用串口自动检测与一键刷新（`🔄`）。
   - **格式兼容**：以 `\r\n`（CR+LF 回车换行）、逗号或空格定界，高精度解析浮点数并支持小数点后三位（`F3`）。

2. **工业级图表核心算法**：
   - **80% 黄金视口跟随**：新数据产生时自动平移视口，保持最新波形吸附在 80% 最佳观察位置；手动拖拽回看后可一键复位。
   - **以光标为中心的缩放**：滚动滚轮时以当前鼠标所在的 X 坐标为支点进行动态时间缩放。
   - **物理空气墙限制**：
     - 向右拖拽老数据时，最新数据最多停留在 80% 视野（禁止观察未来空白）；
     - 向左滑回新数据时，限制第一个数据点不脱离 Y 轴（禁止坐标轴与数据分离）。
   - **10 万点超大内存防爆**：数据缓冲区达 100,000 个时自动 FIFO 裁剪老数据，长期连续运行不泄露内存。
   - **视口渲染裁剪（LOD）**：仅渲染视口内可见数据点，CPU 与 GPU 消耗极低。
   - **辅助基准线**：动态绘制上限阈值（红）、下限阈值（红）、标准值（绿）、动态均值（橙）参考线。

3. **数据自动化留存与追溯（CSV + 图表截图）**：
   - **后台自动静默存盘**：数据流入即刻按天追加保存至 `D:\MyData\yyyy-MM-dd_线缆Name.csv`。
   - **精细时间戳**：记录毫秒级时间戳（`yyyy-MM-dd HH:mm:ss.fff`）与实测值（`F3`），清空图表不丢数据。
   - **【📊 查看数据】**：一键调用系统关联的 Excel / 记事本直接打开今日 CSV 数据文件。
   - **【📷 截取图表】**：精准截取折线图核心区域，智能锚定屏幕可见数据的真实产生时间（彻底解决拖拽回看截图的时间错位 Bug）。

4. **参数自动记忆**：
   - 自动在运行目录保存与读取 `config.json`，线缆名称、通信模式、IP、端口、串口参数与阈值修改即存。

5. **免安装单文件绿色运行**：
   - `dist/LineChart.exe` 内嵌完整 .NET 8 虚拟机与 Skia 绘图引擎，U 盘即插即用，无需目标机预装开发环境。

---

## 🚀 快速测试

1. 启动 `LineChart.exe`，确保顶栏为【网络通讯 (服务端)】并点击【启动服务】（默认端口 3000）；
2. 双击运行 `run_test.bat`，即可向程序推送 200 个围绕 30 波动的三位小数模拟数据流。
